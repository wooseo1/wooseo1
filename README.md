# 서지우 | Jiwoo Seo

컴퓨터공학을 전공하며, 데이터 처리와 시퀀스 모델 실험, 웹 백엔드 구현을 경험했습니다. 금융 데이터를 활용하는 오픈소스 프로젝트에 관심이 있습니다.

## 기술

| 분야 | 사용 경험 |
| --- | --- |
| 프로그래밍 | C++ · Python 기본 활용 |
| 딥러닝 | PyTorch · CUDA 사용 경험, LSTM·Attention·GRU 모델 실험 |
| 웹 개발 | JSP 연결, 로그인 기능 및 데이터베이스 구현 |

## 프로젝트 경험

### 어셈블리 명령어 수열 정정 · CSDC

- AES·SEED 암호 알고리즘 실행에서 어셈블리 명령어 수열 추출
- 추출한 수열에 무작위 오류 명령어를 삽입하여 정정 실험 데이터 구성
- LSTM, LSTM-Attention, GRU-Attention 등 여러 시퀀스 모델 적용
- 모델별 파라미터를 변경하고 암호별 수열을 기준으로 각각 정정 실험 수행

### 문화재 기금 모금 웹사이트 · 웹프로그래밍 2인 프로젝트

- 문화재 기금 모금을 주제로 웹사이트 공동 개발
- 담당: JSP 연결, 로그인 기능 및 데이터베이스 구현

위 항목은 수행 경험을 정리한 내용이며, 현재 이 프로필 저장소에는 프로젝트 소스 코드를 포함하지 않습니다.
