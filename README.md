# 서지우 | Jiwoo Seo

컴퓨터공학을 전공하며, 시퀀스 모델 실험과 웹 백엔드 구현을 경험했습니다. 금융 데이터를 활용하는 오픈소스 프로젝트에 관심이 있습니다.

## 기술

- C++ · Python 기본 활용
- PyTorch · CUDA 사용 경험, LSTM·Attention·GRU 모델 실험
- Java Servlet · JSP · MySQL · JDBC 기반 웹 개발
- AWS EC2 배포 경험

## 프로젝트 경험

### 어셈블리 명령어 수열 정정 | CSDC

- AES·SEED 암호 알고리즘 실행에서 어셈블리 명령어 수열 추출
- 무작위 오류 명령어를 삽입하여 정정 실험 데이터 구성
- LSTM, LSTM-Attention, GRU-Attention 등 여러 모델 적용
- 모델별 파라미터를 변경하고 암호별 수열을 기준으로 각각 실험 수행

### 한(恨) - 국외 유물 환수 기부 플랫폼

2023년 2학기 웹프로그래밍 수업 · 이도윤과 2인 공동 개발

- **서지우:** 프로젝트 기획·백엔드
- **이도윤:** 프로젝트 기획·화면 디자인·프론트엔드
- **기술:** Java Servlet, JSP, MySQL, JDBC, DAO/Bean, AWS EC2
- 회원가입·로그인·로그아웃 및 세션 기반 사용자 상태 처리
- DAO/Bean과 JSP·Servlet을 분리한 데이터 조회·화면 연동
- 기부 내역 저장과 유물별 모금액 갱신을 트랜잭션으로 처리
- AWS EC2에 웹프로젝트 배포

수업용 기부 흐름 구현 프로젝트이며, 실제 카드결제 API 연동은 당시 향후 계획이었습니다. 이 프로필 저장소는 수행 경험을 소개하며 프로젝트 소스 코드는 포함하지 않습니다.

## 관심 분야

금융 데이터 분석, 기업분석 지원 도구, 금융 시계열·투자 위험 분석, 기존 오픈소스의 데이터 처리·분석 기능 개선에 관심이 있습니다.
